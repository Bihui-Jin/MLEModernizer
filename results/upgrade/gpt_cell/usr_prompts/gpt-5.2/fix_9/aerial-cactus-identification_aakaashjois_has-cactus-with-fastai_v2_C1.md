# 1. Kaggle task description

## Task
Create a classifier to predict whether an image contains a cactus.

## Metric
Area under the ROC curve.

## Submission Format
For each ID in the test set, you must predict a probability for the `has_cactus` variable. The file should contain a header and have the following format:

```
id,has_cactus

0017242f54ececa4512b4d7937d1e21e.jpg,0.5
001ee6d8564003107853118ab87df407.jpg,0.5
etc.
```

## Dataset
This dataset contains a large number of 32 x 32 thumbnail images containing aerial photos of a cactus. The file name of an image corresponds to its `id`.

- **train/** - the training set images
- **test/** - the test set images (you must predict the labels of these)
- **train.csv** - the training set labels, indicates whether the image has a cactus (`has_cactus = 1`)
- **sample_submission.csv** - a sample submission file in the correct format

# 5. Code solution

## === cell 0
import os, random
import numpy as np
import torch

SEED = 42
random.seed(SEED)
np.random.seed(SEED)
torch.manual_seed(SEED)
torch.cuda.manual_seed_all(SEED)
torch.backends.cudnn.deterministic = True
torch.backends.cudnn.benchmark = False

from fastai.vision.all import *
import pandas as pd



## === cell 1
labels = pd.read_csv("../input/train.csv")



## === cell 2
train_path = Path("../input/train/train/")
test_path = Path("../input/test/test/")

df = labels.copy()
df["fname"] = df["id"].map(lambda x: str(train_path / x))

nw = min(8, os.cpu_count() or 2)

dls = ImageDataLoaders.from_df(
    df,
    fn_col="fname",
    label_col="has_cactus",
    valid_pct=0.2,
    seed=SEED,
    item_tfms=Resize(224),
    batch_tfms=aug_transforms(),
    bs=128,
    num_workers=nw,
    persistent_workers=True,
    pin_memory=True,
)

from fastai.vision.learner import cnn_learner
from fastai.vision import models
from fastai.metrics import accuracy



## === cell 3
if getattr(dls, "c", None) in (None, 0):
    dls.c = 2  # binary classification: has_cactus {0,1}

learner = cnn_learner(
    dls=dls, arch=models.resnet152, model_dir="../../../../models/", metrics=accuracy
)



## === cell 4
learner.fit_one_cycle(5)



## === cell 5
learner.unfreeze()
learner.fit_one_cycle(10)



## === cell 6
test_files = get_image_files(test_path)
test_dl = dls.test_dl(test_files, with_labels=False)

probs, _ = learner.get_preds(dl=test_dl)  # probs: [n,2] for a 2-class model
predictions = probs.argmax(dim=1)

names = [p.name for p in test_files]
pd.DataFrame({"id": names, "has_cactus": predictions.numpy()}).to_csv(
    "submission.csv", index=False
)
