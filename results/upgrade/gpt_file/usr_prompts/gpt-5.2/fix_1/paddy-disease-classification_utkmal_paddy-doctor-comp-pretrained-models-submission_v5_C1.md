# 1. Kaggle task description

## Task
Develop a model to classify paddy leaf images into one of the nine disease categories or normal leaf.

## Metric
Categorization accuracy.

## Submission Format
```
image_id,label
200001.jpg,normal
200002.jpg,blast
etc.
```

## Dataset
**train.csv** - The training set

- `image_id` - Unique image identifier corresponds to image file names (.jpg) found in the train_images directory.
- `label` - Type of paddy disease, also the target class. There are ten categories, including the normal leaf.
- `variety` - The name of the paddy variety.
- `age` - Age of the paddy in days.

**sample_submission.csv** - Sample submission file.

**train_images** - Training images stored under different sub-directories corresponding to ten target classes. Filename corresponds to the `image_id` column of `train.csv`.

**test_images** - Test set images.

from fastai.imports import *
from fastai.vision.all import *
import timm

timm.list_models()


## === cell 2
models = ['vit_small_patch8_224', 'swin_s3_base_224', 'convnext_small']


## === cell 3
train_dir = Path('/kaggle/input/paddy-disease-classification/train_images')
test_dir = Path('/kaggle/input/paddy-disease-classification/test_images')


## === cell 4
train_files = get_image_files(train_dir)


## === cell 5
import PIL
img = PIL.Image.open(train_files[0])
print(img.size)
img.resize((256, 256))


## === cell 7
dls = ImageDataLoaders.from_folder(
    train_dir, valid_pct=0.2,
    item_tfms=Resize(640, method='pad'),
    batch_tfms=aug_transforms(size=128, min_scale=1.5)
)

dls.show_batch(max_n=10)


## === cell 8
learner = vision_learner(dls, models[2], metrics=error_rate, path='.').to_fp16()


## === cell 9
learner.fine_tune(3, 0.01)


## === cell 10
sample_submission = pd.read_csv('/kaggle/input/paddy-disease-classification/sample_submission.csv')
sample_submission


## === cell 11
test_files = get_image_files(test_dir)
test_files[0]


## === cell 12
test_dl = dls.test_dl(test_files)


## === cell 13
probs,_,idxs = learner.get_preds(dl=test_dl, with_decoded=True)
idxs


## === cell 14
dls.vocab


## === cell 15
mapping = dict(enumerate(dls.vocab))
mapping

idxs.numpy()

results

submission.head()
