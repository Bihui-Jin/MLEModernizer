## Task
Given a dataset of images of dogs, predict the breed of each image.

## Metric
Multi Class Log Loss.

## Submission Format
For each image in the test set, you must predict a probability for each of the different breeds. The file should contain a header and have the following format:
```
id,affenpinscher,afghan_hound,..,yorkshire_terrier
000621fb3cbb32d8935728e48679680e,0.0083,0.0,...,0.0083
etc.
```

- `train.zip` - the training set, you are provided the breed for these dogs
- `test.zip` - the test set, you must predict the probability of each breed for each image
- `sample_submission.csv` - a sample submission file in the correct format
- `labels.csv` - the breeds for the images in the train set

## === cell 0
import os

os.environ["PYTORCH_CUDA_ALLOC_CONF"] = "expandable_segments:True"
from fastai.vision.all import *
import pandas as pd
import torch

torch.backends.cudnn.benchmark = True
NUM_WORKERS = 2  # keep low to stay within OS limits
if torch.cuda.is_available():
    torch.backends.cuda.matmul.allow_tf32 = True
    torch.set_num_threads(8)  # more CPU threads for data loading




## === cell 1
labels = pd.read_csv("../input/dog-breed-identification/labels.csv")
labels["fname"] = labels["id"].apply(lambda x: f"{x}.jpg")
labels




## === cell 2
path = "../input/dog-breed-identification/train"
dls = ImageDataLoaders.from_df(
    labels,
    path,
    fn_col=2,
    bs=32,  # reduced batch size to fit GPU memory
    num_workers=NUM_WORKERS,
    persistent_workers=True,
    pin_memory=True,
    item_tfms=Resize(224),
    batch_tfms=Normalize,
)




## === cell 3
learn = cnn_learner(
    dls, densenet201, loss_func=CrossEntropyLossFlat(), path="."
).to_fp16()




## === cell 4
learn.fine_tune(5, 5e-3)  # fewer epochs – still keeps same schedule
torch.cuda.empty_cache()  # free unused memory before inference




## === cell 5
test_files = get_image_files("../input/dog-breed-identification/test")
test_dl = dls.test_dl(test_files, bs=32)  # same small batch size for inference
preds, _ = learn.get_preds(dl=test_dl)  # no TTA to keep resource usage low
preds = torch.softmax(preds, dim=1)




## === cell 6
sub = pd.DataFrame({"id": [p.stem for p in test_files]})
sub[list(dls.vocab)] = preds.numpy()
sub.to_csv("submission.csv", index=False)
