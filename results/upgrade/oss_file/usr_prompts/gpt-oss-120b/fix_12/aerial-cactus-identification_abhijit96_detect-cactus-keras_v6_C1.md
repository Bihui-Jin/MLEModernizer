## Task
Create a classifier to predict whether an image contains a cactus.

## Metric
Area under the ROC curve.

## Submission Format
For each ID in the test set, you must predict a probability for the `has_cactus` variable. The file should contain a header and have the following format:

```
id,has_cactus
000940378805c44108d287872b2f04ce.jpg,0.5
0017242f54ececa4512b4d7937d1e21e.jpg,0.5
001ee6d8564003107853118ab87df407.jpg,0.5
etc.
```

## Dataset
This dataset contains a large number of 32 x 32 thumbnail images containing aerial photos of a cactus. The file name of an image corresponds to its `id`.

- **train/** - the training set images
- **test/** - the test set images (you must predict the labels of these)
- **train.csv** - the training set labels, indicates whether the image has a cactus (`has_cactus = 1`)
- **sample_submission.csv** - a sample submission file in the correct format

import os
import numpy as np
import pandas as pd
import cv2
import concurrent.futures  # used for parallel image loading
from sklearn.model_selection import train_test_split
from sklearn.ensemble import GradientBoostingClassifier
from sklearn.metrics import roc_auc_score

print("Directories in ../input:", os.listdir("../input"))
np.random.seed(42)


def load_image(base_path, img_name):
    """Read an image (already 32×32) and scale to [0,1]."""
    img_path = os.path.join(base_path, img_name)
    img = cv2.imread(img_path, cv2.IMREAD_COLOR)
    if img is None:
        raise FileNotFoundError(f"Image not found or unable to read: {img_path}")
    return img.astype(np.float32) / 255.0


def get_train_image(name):
    return load_image("../input/train", name)


def get_test_image(name):
    return load_image("../input/test", name)


def load_images_sequential(ids, getter):
    """
    Load images in parallel (while preserving order) to reduce I/O time.
    Returns a (n_samples, 32*32*3) float32 array, identical to the original behavior.
    """
    n = len(ids)
    X = np.empty((n, 32 * 32 * 3), dtype=np.float32)

    def load_one(idx_img):
        idx, img_id = idx_img
        return idx, getter(img_id).ravel()

    max_workers = os.cpu_count() or 1
    with concurrent.futures.ProcessPoolExecutor(max_workers=max_workers) as executor:
        for idx, arr in executor.map(load_one, enumerate(ids)):
            X[idx] = arr
    return X
