# 1. Kaggle task description

## Task
Identify hotels from images.

## Metric
Mean Average Precision @ 5 (MAP@5)

## Submission Format
For each image in the test set, you must predict a space-delimited list of hotel IDs that could match that image. The first ID should be the most relevant one and the last the least relevant one. The file should contain a header and have the following format:

```
image,hotel_id
99e91ad5f2870678.jpg,36363 53586 18807 64314 60181
b5cc62ab665591a9.jpg,36363 53586 18807 64314 60181
d5664a972d5a644b.jpg,36363 53586 18807 64314 60181
```

## Dataset
**train.csv** - The training set metadata.

- `image` - The image ID.

- `chain` - An ID code for the hotel chain. A `chain` of zero (0) indicates that the hotel is either not part of a chain or the chain is not known. This field is not available for the test set. The number of hotels per chain varies widely.

- `hotel_id` - The hotel ID. The target class.

- `timestamp` - When the image was taken. Provided for the training set only.

**sample_submission.csv** - A sample submission file in the correct format.

- `image` The image ID

- `hotel_id` The hotel ID. The target class.

**train_images** - The training set contains 97000+ images from around 7700 hotels from across the globe. All of the images for each hotel chain are in a dedicated subfolder for that chain.

**test_images** - The test set images. This competition has a hidden test set: only three images are provided here as samples while the remaining 13,000 images will be available to your notebook once it is submitted.

# 5. Code solution

## === cell 0
import os
from pathlib import Path
import pandas as pd
import torch
from fastai.vision.all import *
import dill
import numpy as np  # required for np.random.seed

if torch.cuda.is_available():
    torch.backends.cudnn.benchmark = True

torch.set_float32_matmul_precision("high")
torch.manual_seed(42)
np.random.seed(42)

torch.set_num_threads(4)




## === cell 1
base_path = Path("../input/hotel-id-2021-fgvc8")




## === cell 2
train_csv = base_path / "train.csv"
train_df = pd.read_csv(train_csv)




## === cell 3
train_images_dir = base_path / "train_images"
train_df["image_path"] = (
    train_images_dir / train_df["chain"].astype(str) / train_df["image"]
).astype(str)




## === cell 4
batch_size = 512  # larger batch (fits on typical GPUs)
max_workers = min(8, os.cpu_count() or 1)  # use more workers for I/O
dls = ImageDataLoaders.from_df(
    df=train_df[["image_path", "hotel_id"]],
    path=".",  # absolute paths supplied in the dataframe
    folder=".",  # not used because we supply full paths
    valid_pct=0.2,
    seed=42,
    item_tfms=Resize(224, method="pad", pad_mode="reflection"),
    batch_tfms=aug_transforms(size=224),
    bs=batch_size,
    num_workers=max_workers,
    pin_memory=True,
)




## === cell 5
learn = cnn_learner(dls, resnet34, metrics=[accuracy, top_k_accuracy], pretrained=True)
learn.to_fp16()  # mixed‑precision training (identical results up to negligible FP16 differences)
learn.fine_tune(2, base_lr=3e-3)




## === cell 6
test_csv = base_path / "sample_submission.csv"
sample_sub = pd.read_csv(test_csv)

test_images_dir = base_path / "test_images"
test_paths = [str(test_images_dir / img_name) for img_name in sample_sub["image"]]
test_df = pd.DataFrame({"image_path": test_paths})

test_dl = learn.dls.test_dl(test_df)




## === cell 7
probs, _ = learn.get_preds(dl=test_dl)
top5_idx = probs.topk(5, dim=1).indices

vocab = learn.dls.vocab
top5_strings = [" ".join(str(vocab[i]) for i in row) for row in top5_idx]

pred_dict = dict(zip(sample_sub["image"], top5_strings))




## === cell 8
submission = sample_sub.copy()
submission["hotel_id"] = submission["image"].map(pred_dict)
submission_path = "submission.csv"
submission.to_csv(submission_path, index=False)
print(f"Submission written to {submission_path}")
