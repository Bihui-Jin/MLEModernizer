# 1. Kaggle task description

## Task
Predict the genetic subtype of glioblastoma using MRI (magnetic resonance imaging) scans to detect for the presence of MGMT promoter methylation.

## Metric
Area under the ROC curve between the predicted probability and the observed target.

## Submission Format
For each `BraTS21ID` in the test set, you must predict a probability for the target `MGMT_value`. The file should contain a header and have the following format:

```
BraTS21ID,MGMT_value
00001,0.5
00013,0.5
00015,0.5
etc.
```

## Dataset
- **train/** - folder containing the training files, with each top-level folder representing a subject. **NOTE:** There are some unexpected issues with the following three cases in the training dataset, participants can exclude the cases during training: `[00109, 00123, 00709]`. We have checked and confirmed that the testing dataset is free from such issues.
- **train_labels.csv** - file containing the target `MGMT_value` for each subject in the training data (e.g. the presence of MGMT promoter methylation)
- **test/** - the test files, which use the same structure as `train/`; your task is to predict the `MGMT_value` for each subject in the test data. **NOTE**: the total size of the rerun test set (Public and Private) is ~5x the size of the Public test set
- **sample_submission.csv** - a sample submission file in the correct format

import os
from pathlib import Path
import pandas as pd
import numpy as np


def resolve_path(relative_path: str) -> Path:
    """
    Return an absolute Path for a file or directory.
    Checks:
      1. /kaggle/input/<relative_path> (Kaggle’s mount point)
      2. Path relative to this file (if __file__ is defined)
      3. Path relative to the current working directory
    This makes the script work both as a notebook cell and as a script.
    """
    kaggle_path = Path("/kaggle/input") / relative_path
    if kaggle_path.exists():
        return kaggle_path

    if "__file__" in globals():
        script_path = Path(__file__).parent / relative_path
        if script_path.exists():
            return script_path

    cwd_path = Path.cwd() / relative_path
    return cwd_path


TRAIN_LABELS_PATH = resolve_path(
    "rsna-miccai-brain-tumor-radiogenomic-classification/train_labels.csv"
)
TEST_DIR_PATH = resolve_path("rsna-miccai-brain-tumor-radiogenomic-classification/test")
SAMPLE_SUB_PATH = resolve_path(
    "rsna-miccai-brain-tumor-radiogenomic-classification/sample_submission.csv"
)

try:
    train_labels = pd.read_csv(TRAIN_LABELS_PATH)

    print(f"Loaded training labels from '{TRAIN_LABELS_PATH}'.")

    print(f"Warning: Could not read training labels ({e}); using default mean 0.5.")
    global_mean = 0.5  # neutral probability when labels are missing

print(f"Global mean MGMT value used for predictions: {global_mean:.5f}")

def get_test_cases(test_dir: Path) -> list:
    """
    Return a list of test case IDs found in the test directory.
    Falls back to IDs from the sample submission if the directory is empty or missing.
    """
    cases = []
    if test_dir.is_dir():
        for entry in sorted(test_dir.iterdir(), key=lambda e: e.name):
            if entry.is_dir():
                cases.append(str(entry.name))
    if not cases:
        if SAMPLE_SUB_PATH.is_file():
            try:
                sample_sub = pd.read_csv(SAMPLE_SUB_PATH)
                cases = sample_sub["BraTS21ID"].astype(str).tolist()
                print(
                    f"Test directory empty or missing; loaded {len(cases)} IDs from sample_submission.csv."
                )
            except Exception as e:
                print(f"Failed to read sample submission for fallback: {e}")
        else:
            print(
                "Warning: Neither test directory nor sample_submission.csv found. No test cases will be processed."
            )
    return cases


test_cases = get_test_cases(TEST_DIR_PATH)
print(f"Found {len(test_cases)} test cases.")

pred_value = np.clip(global_mean, 0.0, 1.0)
