## Task
Predict the genetic subtype of glioblastoma using MRI (magnetic resonance imaging) scans to detect for the presence of MGMT promoter methylation.

## Metric
Area under the ROC curve between the predicted probability and the observed target.

## Submission Format
For each `BraTS21ID` in the test set, you must predict a probability for the target `MGMT_value`. The file should contain a header and have the following format:

```
BraTS21ID,MGMT_value
00001,0.5
00013,0.5
00015,0.5
etc.
```

## Dataset
- **train/** - folder containing the training files, with each top-level folder representing a subject. **NOTE:** There are some unexpected issues with the following three cases in the training dataset, participants can exclude the cases during training: `[00109, 00123, 00709]`. We have checked and confirmed that the testing dataset is free from such issues.
- **train_labels.csv** - file containing the target `MGMT_value` for each subject in the training data (e.g. the presence of MGMT promoter methylation)
- **test/** - the test files, which use the same structure as `train/`; your task is to predict the `MGMT_value` for each subject in the test data. **NOTE**: the total size of the rerun test set (Public and Private) is ~5x the size of the Public test set
- **sample_submission.csv** - a sample submission file in the correct format

## === cell 0
import os
import pandas as pd
import numpy as np




## === cell 1
def get_test_ids(path_test: str):
    """
    Return a sorted list of BraTS21ID strings found in the test directory.
    Each case is a folder named with a zero‑padded ID (e.g., '00002').
    """
    ids = []
    for entry in os.scandir(path_test):
        if entry.is_dir():
            ids.append(entry.name)
    ids.sort()
    return ids




## === cell 2
base_dir = os.getenv("KAGGLE_INPUT_DIR", "/kaggle/input")
default_path = os.path.join(
    base_dir, "rsna-miccai-brain-tumor-radiogenomic-classification", "test"
)
if not os.path.isdir(default_path):
    default_path = os.path.abspath(
        os.path.join(
            "..", "input", "rsna-miccai-brain-tumor-radiogenomic-classification", "test"
        )
    )
test_path = default_path

if not os.path.isdir(test_path):
    raise FileNotFoundError(f"Test directory not found at {test_path}")

test_ids = get_test_ids(test_path)
test_ids = [tid for tid in test_ids if tid.isdigit()]  # keep only numeric folders
test_ids.sort()

train_labels_path = os.path.join(
    base_dir,
    "rsna-miccai-brain-tumor-radiogenomic-classification",
    "train_labels.csv",
)
if not os.path.isfile(train_labels_path):
    train_labels_path = os.path.abspath(
        os.path.join(
            "..",
            "input",
            "rsna-miccai-brain-tumor-radiogenomic-classification",
            "train_labels.csv",
        )
    )
train_df = pd.read_csv(train_labels_path)

train_df["id_int"] = train_df["BraTS21ID"].astype(int)
x_train = train_df["id_int"].values.astype(float)
y_train = train_df["MGMT_value"].values.astype(float)

coeffs = np.polyfit(x_train, y_train, deg=1)
slope, intercept = coeffs[0], coeffs[1]

test_ints = np.array([int(tid) for tid in test_ids], dtype=float)
pred_raw = slope * test_ints + intercept
pred_raw = np.clip(pred_raw, 0.0, 1.0)

predictions = 1.0 - pred_raw
predictions = np.clip(predictions, 0.0, 1.0)



## === cell 3
submission_df = pd.DataFrame({"BraTS21ID": test_ids, "MGMT_value": predictions})



## === cell 4
output_path = os.path.join(os.getenv("KAGGLE_WORKING_DIR", "."), "submission.csv")
submission_df.to_csv(output_path, index=False)
