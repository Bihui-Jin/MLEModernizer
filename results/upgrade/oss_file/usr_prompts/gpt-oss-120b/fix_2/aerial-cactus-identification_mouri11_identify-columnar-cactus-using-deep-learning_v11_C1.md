# 1. Kaggle task description

## Task
Create a classifier to predict whether an image contains a cactus.

## Metric
Area under the ROC curve.

## Submission Format
For each ID in the test set, you must predict a probability for the `has_cactus` variable. The file should contain a header and have the following format:

```
id,has_cactus
000940378805c44108d287872b2f04ce.jpg,0.5
0017242f54ececa4512b4d7937d1e21e.jpg,0.5
001ee6d8564003107853118ab87df407.jpg,0.5
etc.
```

## Dataset
This dataset contains a large number of 32 x 32 thumbnail images containing aerial photos of a cactus. The file name of an image corresponds to its `id`.

- **train/** - the training set images
- **test/** - the test set images (you must predict the labels of these)
- **train.csv** - the training set labels, indicates whether the image has a cactus (`has_cactus = 1`)
- **sample_submission.csv** - a sample submission file in the correct format

import os
from os.path import join
import numpy as np
import pandas as pd
import tensorflow as tf

train_img_dir = "../input/train/train"
test_img_dir = "../input/test/test"

train_data = pd.read_csv("../input/train.csv")
test_ids = sorted(os.listdir(test_img_dir))  # ensure deterministic order
test_img_paths = [join(test_img_dir, img) for img in test_ids]

img_size = 32


def prep_imgs(img_paths, img_height=img_size, img_width=img_size):
    imgs = [
        tf.keras.preprocessing.image.load_img(p, target_size=(img_height, img_width))
        for p in img_paths
    ]
    arr = (
        np.array([tf.keras.preprocessing.image.img_to_array(img) for img in imgs])
        / 255.0
    )
    return arr


train_img_paths = [join(train_img_dir, img) for img in train_data["id"]]
X_train = prep_imgs(train_img_paths)
y_train = train_data["has_cactus"].values.astype(np.int32)

model = tf.keras.Sequential(
    [
        tf.keras.layers.Conv2D(
            25,
            kernel_size=2,

        tf.keras.layers.Flatten(),

        tf.keras.layers.Dense(2, activation="softmax"),
    ]
)

model.compile(
    loss="sparse_categorical_crossentropy", optimizer="adam", metrics=["accuracy"]
)

model.summary()
