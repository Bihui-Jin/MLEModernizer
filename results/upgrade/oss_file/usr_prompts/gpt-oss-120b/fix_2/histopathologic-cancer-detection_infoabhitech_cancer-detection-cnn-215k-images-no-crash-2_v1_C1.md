# 1. Kaggle task description

## Task
Given a dataset of images from digital pathology scans, predict if the center 32x32px region of a patch contains at least one pixel of tumor tissue. Tumor tissue in the outer region of the patch does not influence the label. 

## Metric
Area under the ROC curve.

## Submission Format
For each `id` in the test set, you must predict a probability that center 32x32px region of a patch contains at least one pixel of tumor tissue. The file should contain a header and have the following format:

```
id,label
0b2ea2a822ad23fdb1b5dd26653da899fbd2c0d5,0
95596b92e5066c5c52466c90b69ff089b39f2737,0
248e6738860e2ebcf6258cdc1f32f299e0c76914,0
etc.
```

## Dataset
Files are named with an image `id`. The `train_labels.csv` file provides the ground truth for the images in the `train` folder. You are predicting the labels for the images in the `test` folder.

# 5. Code solution

## === cell 0
import os, glob
import numpy as np
import pandas as pd
from skimage.io import imread
from tensorflow import keras

print("Input folder list:", os.listdir("../input"))




## === cell 1
train = pd.read_csv("../input/train_labels.csv")
print("Training samples:", len(train))




## === cell 2
def train_image_path(img_id):
    return os.path.join("../input/train/", f"{img_id}.tif")




## === cell 3
train["path"] = train["id"].apply(train_image_path)




## === cell 4
def crop_center(img):
    return img[24:72, 24:72]




## === cell 5
train_imgs = []
for p in train["path"]:
    img = imread(p)  # shape (96,96,3)
    train_imgs.append(crop_center(img))
x_train = np.stack(train_imgs, axis=0).astype("float32") / 255.0
y_train = keras.utils.to_categorical(train["label"].values, num_classes=2)




## === cell 6
img_rows, img_cols = 48, 48
input_shape = (img_rows, img_cols, 3)
batch_size = 128
epochs = 3

model = keras.Sequential(
    [
        keras.layers.Conv2D(
            32, kernel_size=(3, 3), activation="relu", input_shape=input_shape
        ),
        keras.layers.Conv2D(64, (3, 3), activation="relu"),
        keras.layers.MaxPooling2D(pool_size=(2, 2)),
        keras.layers.Dropout(0.2),
        keras.layers.Flatten(),
        keras.layers.Dense(128, activation="relu"),
        keras.layers.Dropout(0.2),
        keras.layers.Dense(2, activation="softmax"),
    ]
)

model.compile(
    loss=keras.losses.CategoricalCrossentropy(),
    optimizer=keras.optimizers.Adadelta(),
    metrics=["accuracy"],
)




## === cell 7
model.fit(x_train, y_train, batch_size=batch_size, epochs=epochs, verbose=1)




## === cell 8
test_files = [f for f in os.listdir("../input/test/") if f.lower().endswith(".tif")]
test_df = pd.DataFrame(test_files, columns=["file"])
test_df["id"] = test_df["file"].apply(lambda x: os.path.splitext(x)[0])
test_df["path"] = test_df["file"].apply(lambda x: os.path.join("../input/test/", x))




## === cell 9
test_imgs = []
for p in test_df["path"]:
    img = imread(p)
    test_imgs.append(crop_center(img))
x_test = np.stack(test_imgs, axis=0).astype("float32") / 255.0




## === cell 10
pred_probs = model.predict(x_test, batch_size=batch_size, verbose=0)[:, 1]




## === cell 11
submission = pd.DataFrame({"id": test_df["id"], "label": pred_probs})
submission.to_csv("submission.csv", index=False)
print("Submission saved to submission.csv with shape:", submission.shape)
