# 1. Kaggle task description

## Task
Classify species of images of animals from camera traps.

## Metric
Categorization accuracy.

## Submission Format
```
Id,Predicted
58857ccf-23d2-11e8-a6a3-ec086b02610b,1
591e4006-23d2-11e8-a6a3-ec086b02610b,5
```

The `Id` column corresponds to the test image id. The `Category` is an integer value that indicates the class of the animal, or `0` to represent the absence of an animal.

## Dataset
Supplementary training data can be downloaded from https://github.com/visipedia/iwildcam_comp.

### Camera Trap Animal Detection Model
We are also providing a general animal detection model.

The model is a TensorFlow Faster-RCNN model with Inception-Resnet-v2 backbone and atrous convolution.

The model and sample code for running the detector over a folder of images can be found [here](https://github.com/microsoft/CameraTraps/blob/master/megadetector.md).

## === cell 1
import json
import glob
import collections

train_json_path = None
for pattern in [
    "/kaggle/input/**/iwildcam2020_train_annotations.json",
    "/kaggle/input/**/iwildcam2020_train_annotations.json",
]:
    matches = glob.glob(pattern, recursive=True)
    if matches:
        train_json_path = matches[0]
        break

if train_json_path is None:
    raise FileNotFoundError("Training annotation JSON not found in /kaggle/input")

with open(train_json_path, "r") as f:
    train_data = json.load(f)

annotations = train_data.get("annotations", [])
category_counts = collections.Counter(a["category_id"] for a in annotations)
if not category_counts:
    raise ValueError("No annotations found in training data")

majority_category = category_counts.most_common(1)[0][0]
print(f"Most common category in training data: {majority_category}")



## === cell 2
sample_sub_path = None
for pattern in [
    "/kaggle/input/**/sample_submission.csv",
    "/kaggle/input/**/sample_submission.csv",
]:
    matches = glob.glob(pattern, recursive=True)
    if matches:
        sample_sub_path = matches[0]
        break

if sample_sub_path is None:
    raise FileNotFoundError("sample_submission.csv not found in /kaggle/input")

submission_df = pd.read_csv(sample_sub_path)
print(f"Loaded sample submission with {len(submission_df)} rows")



## === cell 3
submission_df["Category"] = majority_category

output_path = "/kaggle/working/submission.csv"
submission_df.to_csv(output_path, index=False)
print(f"Submission written to {output_path}")
