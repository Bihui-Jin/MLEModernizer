## Task
Given a dataset of comments from Wikipedia's talk page edits, predict the probability of each comment being toxic.

## Metric
Mean column-wise ROC AUC; the average of the individual AUCs of each predicted column.

For each `id` in the test set, you must predict a probability for each of the six possible types of comment toxicity (toxic, severe_toxic, obscene, threat, insult, identity_hate). The columns must be in the same order as shown below. The file should contain a header and have the following format:

```
id,toxic,severe_toxic,obscene,threat,insult,identity_hate

etc.
```

## Dataset 
- **train.csv** - the training set, contains comments with their binary labels
- **test.csv** - the test set, you must predict the toxicity probabilities for these comments.
- **sample_submission.csv** - a sample submission file in the correct format

import os, pandas as pd

comp_dir = "../input/jigsaw-toxic-comment-classification-challenge"
print("Files in competition directory:", os.listdir(comp_dir))



## === cell 1
train_path = os.path.join(comp_dir, "train.csv")
test_path = os.path.join(comp_dir, "test.csv")
sample_sub_path = os.path.join(comp_dir, "sample_submission.csv")

train_df = pd.read_csv(train_path)
test_df = pd.read_csv(test_path)
sample_sub = pd.read_csv(sample_sub_path)

print("Train shape:", train_df.shape)
print("Test shape :", test_df.shape)



## === cell 2
label_cols = ["toxic", "severe_toxic", "obscene", "threat", "insult", "identity_hate"]

label_means = train_df[label_cols].mean()
print("Label means (baseline probabilities):")
print(label_means)



## === cell 3
submission = sample_sub.copy()

for col in label_cols:
    submission[col] = label_means[col]

assert len(submission) == len(test_df), "Submission row count must match test set."



## === cell 4
output_path = "submission.csv"
submission.to_csv(output_path, index=False)
print(f"Submission written to {output_path}")
