# 1. Kaggle task description

## Task
Use binary leaf images and extracted features to identify the species of plant.

## Metric
Multi-class log loss. 

The submitted probabilities for a given device are not required to sum to one because they are rescaled prior to being scored (each row is divided by the row sum), but they need to be in the range of [0, 1]. In order to avoid the extremes of the log function, predicted probabilities are replaced with \\(max(min(p,1-10^{-15}),10^{-15})\\).

## Submission Format
You must submit a csv file with the image id, all candidate species names, and a probability for each species. The order of the rows does not matter. The file must have a header and should look like the following:

id,Acer_Capillipes,Acer_Circinatum,Acer_Mono,...
2,0.1,0.5,0,0.2,...
5,0,0.3,0,0.4,...
6,0,0,0,0.7,...
etc.

## Dataset
The dataset consists of images of leaf specimens which have been converted to binary black leaves against white backgrounds. 

Three sets of features are also provided per image: a shape contiguous descriptor, an interior texture histogram, and a ﬁne-scale margin histogram. 

For each feature, a 64-attribute vector is given per leaf sample.

### File descriptions
- **train.csv** - the training set
- **test.csv** - the test set
- **sample_submission.csv** - a sample submission file in the correct format
- **images/** - the image files (each image is named with its corresponding id)

### Data fields
- **id** - an anonymous id unique to an image
- **margin_1, margin_2, margin_3, ..., margin_64** - each of the 64 attribute vectors for the margin feature
- **shape_1, shape_2, shape_3, ..., shape_64** - each of the 64 attribute vectors for the shape feature
- **texture_1, texture_2, texture_3, ..., texture_64** - each of the 64 attribute vectors for the texture feature

import numpy as np
import pandas as pd
from sklearn.model_selection import KFold
from sklearn.preprocessing import StandardScaler
from sklearn.neural_network import MLPClassifier
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis
from sklearn.ensemble import GradientBoostingClassifier
import matplotlib.pyplot as plt
import seaborn as sns



## === cell 1
data_train = pd.read_csv("../input/train.csv")



## === cell 2
data_train.head()



## === cell 3
data_train.drop(["id", "species"], axis=1).describe()



## === cell 4
data_train["species"].describe()



## === cell 5
plt.figure(figsize=(30, 30))
corr_matrix = data_train.drop(["id", "species"], axis=1).corr().abs()
sns.heatmap(corr_matrix)



## === cell 6
upper = corr_matrix.where(np.triu(np.ones(corr_matrix.shape), k=1).astype(bool))
to_drop = [column for column in upper.columns if any(upper[column] > 0.75)]
feature_selected = data_train.drop(["id", "species"] + to_drop, axis=1)



## === cell 7
plt.figure(figsize=(30, 30))
sns.heatmap(feature_selected.corr())



## === cell 8
featureScaler = StandardScaler()
featureScaler.fit(feature_selected)
feature_scaled = featureScaler.transform(feature_selected)



## === cell 9
classifiers = [
    MLPClassifier(hidden_layer_sizes=(256, 128), max_iter=600, random_state=42),
    LinearDiscriminantAnalysis(),
]
for clf in classifiers:
    print(f"Classifier: {type(clf).__name__}")
    kfold = KFold(n_splits=5, shuffle=True, random_state=42)
    for train_idx, test_idx in kfold.split(data_train):
        clf.fit(feature_scaled[train_idx], data_train["species"].iloc[train_idx])
        score = clf.score(
            feature_scaled[test_idx], data_train["species"].iloc[test_idx]
        )
        print(f"  Fold score: {score:.4f}")



## === cell 10
final_clf = GradientBoostingClassifier(random_state=42)
final_clf.fit(feature_scaled, data_train["species"])



## === cell 11
data_test = pd.read_csv("../input/test.csv")
feature_test = featureScaler.transform(data_test.drop(["id"] + to_drop, axis=1))
pred_proba = final_clf.predict_proba(feature_test)
submission = pd.concat(
    [data_test[["id"]], pd.DataFrame(pred_proba, columns=final_clf.classes_)], axis=1
)
submission.to_csv("submission.csv", index=False)
