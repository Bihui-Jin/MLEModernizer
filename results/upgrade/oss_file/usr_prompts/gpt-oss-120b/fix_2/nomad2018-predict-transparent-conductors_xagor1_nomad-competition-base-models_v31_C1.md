# 1. Kaggle task description

## Task
Predict the formation energy and bandgap energy of a material.

## Metric
Column-wise root mean squared logarithmic error.

## Submission Format
For each id in the test set, you must predict a value for both formation_energy_ev_natom and bandgap_energy_ev. The file should contain a header and have the following format:
```
id,formation_energy_ev_natom,bandgap_energy_ev
1,0.1779,1.8892
2,0.1779,1.8892
3,0.1779,1.8892
...
```

## Dataset
The following information has been included:

- Spacegroup (a label identifying the symmetry of the material)
- Total number of Al, Ga, In and O atoms in the unit cell ($\N_{total}$)
- Relative compositions of Al, Ga, and In (x, y, z)
- Lattice vectors and angles: lv1, lv2, lv3 (which are lengths given in units of angstroms ($10^{-10}$ meters) and $\alpha, \beta, \gamma$ (which are angles in degrees between 0° and 360°)

Note: For each line of the CSV file, the corresponding spatial positions of all of the atoms in the unit cell (expressed in Cartesian coordinates) are provided as a separate file.

train.csv - contains a set of materials for which the bandgap and formation energies are provided

test.csv - contains the set of materials for which you must predict the bandgap and formation energies

/{train|test}/{id}/geometry.xyz - files with spatial information about the material. The file name corresponds to the id in the respective csv files.

## === cell 0
import os, warnings
import numpy as np, pandas as pd
import xgboost as xgb
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_log_error

warnings.filterwarnings("ignore")



## === cell 1
path = "../input"
train_df = pd.read_csv(os.path.join(path, "train.csv"))
test_df = pd.read_csv(os.path.join(path, "test.csv"))



## === cell 2
train_ids = train_df["id"].copy()
test_ids = test_df["id"].copy()

target_bg = train_df["bandgap_energy_ev"].copy()
target_fe = train_df["formation_energy_ev_natom"].copy()

train_features = train_df.drop(
    columns=["id", "formation_energy_ev_natom", "bandgap_energy_ev"]
)
test_features = test_df.drop(columns=["id"])

train_features = pd.get_dummies(
    train_features, columns=["spacegroup"], prefix="spacegroup"
)
test_features = pd.get_dummies(
    test_features, columns=["spacegroup"], prefix="spacegroup"
)

train_features, test_features = train_features.align(
    test_features, join="left", axis=1, fill_value=0
)



## === cell 3
X_tr, X_val, y_bg_tr, y_bg_val, y_fe_tr, y_fe_val = train_test_split(
    train_features, target_bg, target_fe, test_size=0.2, random_state=42
)




## === cell 4
def rmsle(y_true, y_pred):
    y_pred = np.maximum(y_pred, 0)
    return np.sqrt(mean_squared_log_error(y_true, y_pred))


model_bg = xgb.XGBRegressor(
    n_estimators=300,
    max_depth=4,
    learning_rate=0.05,
    subsample=0.8,
    colsample_bytree=0.8,
    random_state=42,
    n_jobs=5,
    objective="reg:squarederror",
)
model_bg.fit(X_tr, y_bg_tr)
bg_val_pred = model_bg.predict(X_val)
bg_rmsle = rmsle(y_bg_val, bg_val_pred)
print("Bandgap validation RMSLE:", bg_rmsle)

model_fe = xgb.XGBRegressor(
    n_estimators=300,
    max_depth=4,
    learning_rate=0.05,
    subsample=0.8,
    colsample_bytree=0.8,
    random_state=42,
    n_jobs=5,
    objective="reg:squarederror",
)
model_fe.fit(X_tr, y_fe_tr)
fe_val_pred = model_fe.predict(X_val)
fe_rmsle = rmsle(y_fe_val, fe_val_pred)
print("Formation energy validation RMSLE:", fe_rmsle)

print("Combined RMSLE:", (bg_rmsle + fe_rmsle) / 2)



## === cell 5
model_bg.fit(train_features, target_bg)
model_fe.fit(train_features, target_fe)

bg_test_pred = np.maximum(model_bg.predict(test_features), 0)
fe_test_pred = np.maximum(model_fe.predict(test_features), 0)



## === cell 6
submission = pd.DataFrame(
    {
        "id": test_ids,
        "formation_energy_ev_natom": fe_test_pred,
        "bandgap_energy_ev": bg_test_pred,
    }
)
submission_path = "submission.csv"
submission.to_csv(submission_path, index=False)
print(f"Submission written to {submission_path}")
