# 1. Kaggle task description

## Task
Predict the genetic subtype of glioblastoma using MRI (magnetic resonance imaging) scans to detect for the presence of MGMT promoter methylation.

## Metric
Area under the ROC curve between the predicted probability and the observed target.

## Submission Format
For each `BraTS21ID` in the test set, you must predict a probability for the target `MGMT_value`. The file should contain a header and have the following format:

```
BraTS21ID,MGMT_value
00001,0.5
00013,0.5
00015,0.5
etc.
```

## Dataset
- **train/** - folder containing the training files, with each top-level folder representing a subject. **NOTE:** There are some unexpected issues with the following three cases in the training dataset, participants can exclude the cases during training: `[00109, 00123, 00709]`. We have checked and confirmed that the testing dataset is free from such issues.
- **train_labels.csv** - file containing the target `MGMT_value` for each subject in the training data (e.g. the presence of MGMT promoter methylation)
- **test/** - the test files, which use the same structure as `train/`; your task is to predict the `MGMT_value` for each subject in the test data. **NOTE**: the total size of the rerun test set (Public and Private) is ~5x the size of the Public test set
- **sample_submission.csv** - a sample submission file in the correct format

def load_test_T2W_images(path_test):
    """
    Load up to five T2W slices per case, resize to 150x150,
    stack to 3 channels and normalize.
    Returns a list of five NumPy arrays (one per slice position).
    """
    IMG_PX_SIZE = 150
    slice_arrays = [[] for _ in range(5)]

    case_dirs = sorted(
        [d for d in os.scandir(path_test) if d.is_dir()], key=lambda x: x.path
    )
    for case in case_dirs:
        modality_dirs = sorted(
            [d for d in os.scandir(case.path) if d.is_dir()], key=lambda x: x.path
        )
        if len(modality_dirs) < 4:
            continue
        t2w_dir = modality_dirs[3]
        img_files = sorted(
            [f for f in os.scandir(t2w_dir) if f.is_file()], key=lambda x: x.path
        )

        count = 0
        for img_f in img_files:
            ds = dicom.dcmread(img_f.path)
            if ds.pixel_array.sum() <= 100000:
                continue

            img_resized = tf.image.resize(
                ds.pixel_array[..., np.newaxis], (IMG_PX_SIZE, IMG_PX_SIZE)
            )
            img_resized = tf.squeeze(img_resized).numpy()

            stacked = np.stack([img_resized] * 3, axis=-1)

            max_val = stacked.max()
            if max_val != 0:
                stacked = stacked / max_val

            if stacked.sum() > 2500:
                slice_arrays[count].append(stacked)
                count += 1
                if count >= 5:
                    break

    result = []
    for arr in slice_arrays:
        if len(arr) == 0:
            result.append(np.empty((0, IMG_PX_SIZE, IMG_PX_SIZE, 3), dtype=np.float32))
        else:
            batch = np.array(arr, dtype=np.float32)
            batch_max = batch.max()
            if batch_max != 0:
                batch = batch / batch_max
            result.append(batch)
    return result

def create_sub(path_test, p1, p2, p3, p4, p5):
    """
    Build the submission DataFrame.
    path_test : folder containing case sub‑folders.
    p1‑p5    : probability vectors for the five slice positions.
    """
    case_dirs = sorted(
        [d for d in os.scandir(path_test) if d.is_dir()], key=lambda x: x.path
    )
    ids = [os.path.basename(d.path) for d in case_dirs]

    probs = np.column_stack([p1, p2, p3, p4, p5])
    avg_prob = probs.mean(axis=1)

    df = pd.DataFrame({"BraTS21ID": ids, "MGMT_value": avg_prob})
    return df
