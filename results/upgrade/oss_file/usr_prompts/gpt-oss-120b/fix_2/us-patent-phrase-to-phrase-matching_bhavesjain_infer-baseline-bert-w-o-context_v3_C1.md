# 1. Kaggle task description

## Task
Given pairs of phrases (an `anchor` and a `target` phrase), build a model to rate how similar they are.  

## Metric
Pearson correlation coefficient.

## Submission Format
For each `id` (representing a pair of phrases) in the test set, you must predict the similarity `score`. The file should contain a header and have the following format:

```
id,score
4112d61851461f60,0
09e418c93a776564,0.25
36baf228038e314b,1
etc.

```

## Dataset
The scores are in the 0-1 range with increments of 0.25 with the following meanings:

- **1.0** - Very close match. This is typically an exact match except possibly for differences in conjugation, quantity (e.g. singular vs. plural), and addition or removal of stopwords (e.g. "the", "and", "or").
- **0.75** - Close synonym, e.g. "mobile phone" vs. "cellphone". This also includes abbreviations, e.g. "TCP" -> "transmission control protocol".
- **0.5** - Synonyms which don't have the same meaning (same function, same properties). This includes broad-narrow (hyponym) and narrow-broad (hypernym) matches.
- **0.25** - Somewhat related, e.g. the two phrases are in the same high level domain but are not synonyms. This also includes antonyms.
- **0.0** - Unrelated.

Files
-----

- **train.csv** - the training set, containing phrases, contexts, and their similarity scores
- **test.csv** - the test set set, identical in structure to the training set but without the score
- **sample_submission.csv** - a sample submission file in the correct format

Columns
-------

- `id` - a unique identifier for a pair of phrases
- `anchor` - the first phrase
- `target` - the second phrase
- `context` - the [CPC classification (version 2021.05)](https://en.wikipedia.org/wiki/Cooperative_Patent_Classification), which indicates the subject within which the similarity is to be scored
- `score` - the similarity. This is sourced from a combination of one or more manual expert ratings.

## === cell 0
import os
import re
import numpy as np
import pandas as pd
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity



## === cell 1
train_path = "/kaggle/input/us-patent-phrase-to-phrase-matching/train.csv"
test_path = "/kaggle/input/us-patent-phrase-to-phrase-matching/test.csv"
sample_sub_path = (
    "/kaggle/input/us-patent-phrase-to-phrase-matching/sample_submission.csv"
)

train_df = pd.read_csv(train_path)
test_df = pd.read_csv(test_path)




## === cell 2
def clean_text(text):
    """
    Basic cleaning: lowercase, keep letters/numbers/spaces, collapse multiple spaces.
    """
    text = str(text).lower()
    text = re.sub(r"[^a-z0-9\s]", " ", text)
    text = re.sub(r"\s+", " ", text).strip()
    return text


train_df["anchor_clean"] = train_df["anchor"].apply(clean_text)
train_df["target_clean"] = train_df["target"].apply(clean_text)
test_df["anchor_clean"] = test_df["anchor"].apply(clean_text)
test_df["target_clean"] = test_df["target"].apply(clean_text)



## === cell 3
vectorizer = TfidfVectorizer(
    ngram_range=(1, 2),  # unigrams & bigrams improve coverage
    max_features=20000,  # limit size for speed/memory
    norm="l2",
    sublinear_tf=True,
)

all_texts = pd.concat([train_df["anchor_clean"], train_df["target_clean"]])
vectorizer.fit(all_texts)



## === cell 4
anchor_vec = vectorizer.transform(test_df["anchor_clean"])
target_vec = vectorizer.transform(test_df["target_clean"])

dot_product = anchor_vec.multiply(target_vec).sum(axis=1).A1
anchor_norm = np.sqrt(anchor_vec.multiply(anchor_vec).sum(axis=1)).A1
target_norm = np.sqrt(target_vec.multiply(target_vec).sum(axis=1)).A1
cos_sim = dot_product / (anchor_norm * target_norm + 1e-10)  # avoid div‑0

scores = (cos_sim + 1.0) / 2.0



## === cell 5
submission_df = pd.DataFrame({"id": test_df["id"], "score": scores})

submission_df = submission_df[["id", "score"]]

output_path = "submission.csv"
submission_df.to_csv(output_path, index=False)

print(f"Submission saved to {output_path} – shape: {submission_df.shape}")
