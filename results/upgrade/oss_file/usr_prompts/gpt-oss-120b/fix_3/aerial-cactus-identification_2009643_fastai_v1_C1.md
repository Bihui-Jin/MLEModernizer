Create a classifier to predict whether an image contains a cactus.

## Metric

## Submission Format

```
id,has_cactus

0017242f54ececa4512b4d7937d1e21e.jpg,0.5
001ee6d8564003107853118ab87df407.jpg,0.5
etc.
```

## Dataset
This dataset contains a large number of 32 x 32 thumbnail images containing aerial photos of a cactus. The file name of an image corresponds to its `id`.

- **train/** - the training set images
- **test/** - the test set images (you must predict the labels of these)
- **train.csv** - the training set labels, indicates whether the image has a cactus (`has_cactus = 1`)
- **sample_submission.csv** - a sample submission file in the correct format

## === cell 0
from pathlib import Path
import pandas as pd
import torch
from fastai.vision.all import *

base_path = Path("../input/aerial-cactus-identification")

train_df = pd.read_csv(base_path / "train.csv")
test_df = pd.read_csv(base_path / "sample_submission.csv")

dls = ImageDataLoaders.from_df(
    df=train_df,
    path=base_path / "train",
    fn_col="id",
    label_col="has_cactus",
    valid_pct=0.01,
    seed=42,
    item_tfms=Resize(128),
    batch_tfms=aug_transforms(
        do_flip=True,
        flip_vert=True,
        max_rotate=10.0,
        max_zoom=1.1,
        max_lighting=0.2,
        max_warp=0.2,
        p_affine=0.75,
        p_lighting=0.75,
    )
    + [Normalize.from_stats(*imagenet_stats)],
    bs=64,
    device=torch.device("cuda:0") if torch.cuda.is_available() else torch.device("cpu"),
)

learn = cnn_learner(dls, models.densenet161, metrics=[error_rate, accuracy])



## === cell 1
lr = 3e-2
learn.fit_one_cycle(5, slice(lr))



## === cell 2
test_df["id"] = test_df["id"].apply(lambda x: str(base_path / "test" / x))

test_dl = learn.dls.test_dl(test_df["id"])

preds, _ = learn.get_preds(dl=test_dl)

probs = torch.nn.functional.softmax(preds, dim=1)[:, 1]

test_df["has_cactus"] = probs.cpu().numpy()
test_df.to_csv("submission.csv", index=False)
