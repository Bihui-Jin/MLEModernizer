# 1. Kaggle task description

## Task
Predict engagement with a pet's profile based on the photograph for that profile.

## Metric
Root mean squared error.

## Submission Format
For each `Id` in the test set, you must predict a probability for the target variable, `Pawpularity`. The file should contain a header and have the following format:

```
Id, Pawpularity
0008dbfb52aa1dc6ee51ee02adf13537, 99.24
0014a7b528f1682f0cf3b73a991c17a0, 61.71
0019c1388dfcd30ac8b112fb4250c251, 6.23
00307b779c82716b240a24f028b0031b, 9.43
00320c6dd5b4223c62a9670110d47911, 70.89
etc.
```

## Dataset
- **train/** - Folder containing training set photos of the form **{id}.jpg**, where **{id}** is a unique Pet Profile ID.
- **train.csv** - Metadata (described below) for each photo in the training set as well as the target, the photo's Pawpularity score. The Id column gives the photo's unique Pet Profile ID corresponding the photo's file name.

The train.csv and test.csv files contain metadata for photos in the training set and test set, respectively. Each pet photo is labeled with the value of 1 (Yes) or 0 (No) for each of the following features:

- **Focus** - Pet stands out against uncluttered background, not too close / far.
- **Eyes** - Both eyes are facing front or near-front, with at least 1 eye / pupil decently clear.
- **Face** - Decently clear face, facing front or near-front.
- **Near** - Single pet taking up significant portion of photo (roughly over 50% of photo width or height).
- **Action** - Pet in the middle of an action (e.g., jumping).
- **Accessory** - Accompanying physical or digital accessory / prop (i.e. toy, digital sticker), excluding collar and leash.
- **Group** - More than 1 pet in the photo.
- **Collage** - Digitally-retouched photo (i.e. with digital photo frame, combination of multiple photos).
- **Human** - Human in the photo.
- **Occlusion** - Specific undesirable objects blocking part of the pet (i.e. human, cage or fence). Note that not all blocking objects are considered occlusion.
- **Info** - Custom-added text or labels (i.e. pet name, description).
- **Blur** - Noticeably out of focus or noisy, especially for the pet's eyes and face. For Blur entries, "Eyes" column is always set to 0.

img_augmentation = keras.Sequential(
    [
        layers.RandomRotation(factor=0.15),
        layers.RandomTranslation(height_factor=0.1, width_factor=0.1),
        layers.RandomFlip(),
        layers.RandomContrast(factor=0.1),
    ],
    name="img_augmentation",
)



## === cell 3
tabular_columns = [
    "Subject Focus",
    "Eyes",
    "Face",
    "Near",
    "Action",
    "Accessory",
    "Group",
    "Collage",
    "Human",
    "Occlusion",
    "Info",
    "Blur",
]


def rmse(y_true, y_pred):
    y_true = tf.cast(y_true, tf.float32)
    return tf.sqrt(tf.reduce_mean(tf.square(y_true - y_pred)))


def get_tabular_prediction_model(inputs):
    width = 32
    depth = 3
    activation = "relu"
    kernel_regularizer = keras.regularizers.l2()
    x = keras.layers.Dense(
        width,
        activation=activation,
        kernel_regularizer=kernel_regularizer,
    )(inputs)
    for i in range(depth):
        if i == 0:
            x = inputs
        x = keras.layers.Dense(
            width,
            activation=activation,
            kernel_regularizer=kernel_regularizer,
        )(x)
        if (i + 1) % 3 == 0:
            x = keras.layers.Concatenate()([x, inputs])
    return x


def get_model():
    image_inputs = layers.Input(shape=(image_size, image_size, 3), name="image_input")
    image_x = img_augmentation(image_inputs)
    backbone = EfficientNetB0(
        include_top=False,
        weights="imagenet",
        input_tensor=image_x,
    )
    backbone.trainable = False
    image_x = layers.GlobalAveragePooling2D(name="avg_pool")(backbone.output)
    image_x = layers.Dropout(0.2, name="top_dropout")(image_x)

    tabular_inputs = layers.Input(shape=(len(tabular_columns),), name="tabular_input")
    tabular_x = get_tabular_prediction_model(tabular_inputs)

    combined = layers.Concatenate(axis=1)([image_x, tabular_x])
    outputs = layers.Dense(1, name="output")(combined)

    model = keras.Model(
        inputs=[image_inputs, tabular_inputs],
        outputs=outputs,
        name="EfficientNetHybrid",
    )
    model.compile(
        optimizer=keras.optimizers.Adam(1e-3),
        loss=rmse,
        metrics=["mae", "mape"],
    )
    return model


with strategy.scope():
    model_up = get_model()

weights_path = "../input/b0-weights/pet_trained_weights_v6.h5"
if os.path.exists(weights_path):
    model_up.load_weights(weights_path)
else:
    print("Pre‑trained weight file not found – using ImageNet initialization.")

def preprocess_example(image_path, tabular_vals):
    image_string = tf.io.read_file(image_path)
    image = tf.image.decode_jpeg(image_string, channels=3)
    image = tf.image.resize(image, (image_size, image_size))
    image = tf.cast(image, tf.float32) / 255.0  # normalise to [0,1]
    tabular_vals = tf.cast(tabular_vals, tf.float32)

    return {"image_input": image, "tabular_input": tabular_vals}


ds_test = (
    tf.data.Dataset.from_tensor_slices(
        (test["file_path"].values, test[tabular_columns].values)
    )
    .map(
        lambda img_path, tab: preprocess_example(img_path, tab),
        num_parallel_calls=tf.data.AUTOTUNE,
    )
    .batch(batch_size)
    .prefetch(tf.data.AUTOTUNE)
)

preds = model_up.predict(ds_test, verbose=1).reshape(-1)

test["Pawpularity"] = preds
submission = test[["Id", "Pawpularity"]]
submission.to_csv("submission.csv", index=False)
print("Saved submission.csv with", submission.shape[0], "rows.")
