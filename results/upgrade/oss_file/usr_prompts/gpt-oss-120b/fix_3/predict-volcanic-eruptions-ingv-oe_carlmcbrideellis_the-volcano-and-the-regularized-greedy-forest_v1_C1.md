# 1. Kaggle task description

## Overview
Given readings from several seismic sensors around a volcano, estimate how long it will be until the next eruption.

## Metric
Mean absolute error (MAE) between the predicted loss and the actual loss.

## Submission Format
For every id in the test set, you should predict the time until the next eruption. The file should contain a header and have the following format:

```
segment_id,time_to_eruption
1,1
2,2
3,3
etc.
```

## Data
### Dataset Description

#### Files
**train.csv** Metadata for the train files.

- `segment_id`: ID code for the data segment. Matches the name of the associated data file.
- `time_to_eruption`: The target value, the time until the next eruption.

**[train|test]/*.csv**: the data files. Each file contains ten minutes of logs from ten different sensors arrayed around a volcano. The readings have been normalized within each segment, in part to ensure that the readings fall within the range of int16 values. If you are using the Pandas library you may find that you still need to load the data as float32 due to the presence of some nulls.

## === cell 0
import pandas as pd
import numpy as np
import os
from rgf.sklearn import RGFRegressor




## === cell 1
BASE_PATH = "/kaggle/input/predict-volcanic-eruptions-ingv-oe"
TRAIN_META_PATH = os.path.join(BASE_PATH, "train.csv")
TEST_META_PATH = os.path.join(
    BASE_PATH, "test.csv"
)  # may not exist; we use sample for ids
TRAIN_SEG_DIR = os.path.join(BASE_PATH, "train")
TEST_SEG_DIR = os.path.join(BASE_PATH, "test")
SAMPLE_SUB_PATH = os.path.join(BASE_PATH, "sample_submission.csv")

train_meta = pd.read_csv(TRAIN_META_PATH)  # columns: segment_id, time_to_eruption
sample_submission = pd.read_csv(SAMPLE_SUB_PATH)  # contains test segment_id list




## === cell 2
def load_segment_means(seg_dir, segment_ids):
    """
    For each segment_id, read its CSV file and compute the mean of each sensor column.
    Returns a DataFrame indexed by segment_id with 10 feature columns (sensor_1..sensor_10).
    """
    feature_rows = []
    for seg_id in segment_ids:
        file_path = os.path.join(seg_dir, f"{seg_id}.csv")
        df = pd.read_csv(file_path, dtype=np.float32)
        means = df.mean(skipna=True).values  # expects 10 values
        feature_rows.append([seg_id] + list(means))
    cols = ["segment_id"] + [f"sensor_{i}" for i in range(1, 11)]
    return pd.DataFrame(feature_rows, columns=cols).set_index("segment_id")


X_train = load_segment_means(TRAIN_SEG_DIR, train_meta["segment_id"])
y_train = train_meta.set_index("segment_id")["time_to_eruption"]
X_test = load_segment_means(TEST_SEG_DIR, sample_submission["segment_id"])

X_train = X_train.fillna(0)
X_test = X_test.fillna(0)




## === cell 3
regressor = RGFRegressor(
    max_leaf=2000, algorithm="RGF_Sib", test_interval=100, loss="LS", verbose=False
)

regressor.fit(X_train.values, y_train.values)
predictions = regressor.predict(X_test.values)




## === cell 4
submission = sample_submission.copy()
submission["time_to_eruption"] = predictions
submission.to_csv("submission.csv", index=False)
