## Task
Detect apple diseases from images.

## Metric
Mean F1-Score

## Submission Format
labels should be a space-delimited list.

The file should contain a header and have the following format:

```
image, labels

```

## Dataset
**train.csv** - the training set metadata.

- `image` - the image ID.
- `labels` - the target classes, a space delimited list of all diseases found in the image. Unhealthy leaves with too many diseases to classify visually will have the `complex` class, and may also have a subset of the diseases identified.

**sample_submission.csv** - A sample submission file in the correct format.

- `image`
- `labels`

**train_images** - The training set images.

**test_images** - The test set images. This competition has a hidden test set: only three images are provided here as samples while the remaining 5,000 images will be available to your notebook once it is submitted.

# 5. Code solution

## === cell 0
import numpy as np, pandas as pd, os
from fastai.vision.all import *
import matplotlib.pyplot as plt

plt.style.use("ggplot")
BASE_PATH = Path("/kaggle/input/plant-pathology-2021-fgvc8")
torch.backends.cudnn.benchmark = True




## === cell 1
train_df = pd.read_csv(BASE_PATH / "train.csv")
train_img_path = BASE_PATH / "train_images"
test_img_path = BASE_PATH / "test_images"

num_workers = min(8, os.cpu_count() or 1)

dblock = DataBlock(
    blocks=(ImageBlock, MultiCategoryBlock),
    get_x=ColReader("image", pref=str(train_img_path) + "/"),
    get_y=lambda o: o["labels"].split(" "),
    splitter=RandomSplitter(valid_pct=0.2, seed=42),
    item_tfms=Resize(224),  # small size for speed
)

dls = dblock.dataloaders(train_df, bs=128, num_workers=num_workers, pin_memory=True)




## === cell 2
learn = cnn_learner(
    dls, resnet34, loss_func=BCEWithLogitsLossFlat(), metrics=accuracy_multi
)
learn = learn.to_fp16()
learn.fine_tune(2, base_lr=1e-3)




## === cell 3
test_files = get_image_files(test_img_path).sorted()
test_dl = learn.dls.test_dl(test_files, bs=128)
preds, _ = learn.get_preds(dl=test_dl)  # (num_test, num_classes)




## === cell 4
vocab = learn.dls.vocab
labels_list = []
for prob in preds:
    lbls = [c for c, p in zip(vocab, prob) if p > 0.5]
    if not lbls:  # guarantee at least one label
        lbls = ["healthy"]
    labels_list.append(" ".join(lbls))

submission = pd.DataFrame(
    {"image": [f.name for f in test_files], "labels": labels_list}
)

submission.to_csv("submission.csv", index=False)
