# 1. Kaggle task description

## Task
Detect apple diseases from images.

## Metric
Mean F1-Score

## Submission Format
labels should be a space-delimited list.

The file should contain a header and have the following format:

```
image, labels
85f8cb619c66b863.jpg,healthy
ad8770db05586b59.jpg,healthy
c7b03e718489f3ca.jpg,healthy
```

## Dataset
**train.csv** - the training set metadata.

- `image` - the image ID.
- `labels` - the target classes, a space delimited list of all diseases found in the image. Unhealthy leaves with too many diseases to classify visually will have the `complex` class, and may also have a subset of the diseases identified.

**sample_submission.csv** - A sample submission file in the correct format.

- `image`
- `labels`

**train_images** - The training set images.

**test_images** - The test set images. This competition has a hidden test set: only three images are provided here as samples while the remaining 5,000 images will be available to your notebook once it is submitted.

# 5. Code solution

## === cell 0
import numpy as np, pandas as pd, torch, pathlib
from fastai.vision.all import *

torch.backends.cudnn.benchmark = True
defaults.num_workers = (
    8  # raised from 4 to leverage additional CPU cores for faster loading
)



## === cell 1
defaults.device = torch.device("cuda" if torch.cuda.is_available() else "cpu")



## === cell 2
PATH = Path("/kaggle/input/plant-pathology-2021-fgvc8/")



## === cell 3
df = pd.read_csv(PATH / "train.csv")



## === cell 4
dls = ImageDataLoaders.from_df(
    df,
    path=PATH,
    folder="train_images",
    label_col="labels",
    label_delim=" ",
    y_block=MultiCategoryBlock,  # correct block for space‑delimited multi‑labels
    valid_pct=0.2,
    seed=42,
    bs=128,
    item_tfms=Resize(224),  # single resize to target size
    batch_tfms=aug_transforms(),  # default augmentations (including random crops, flips, etc.)
)



## === cell 5
learn = cnn_learner(dls, resnet34, metrics=accuracy_multi)
learn = learn.to_fp16()  # mixed‑precision for faster GPU computation
learn.fine_tune(1, base_lr=1e-3)



## === cell 6
test_path = PATH / "test_images"
test_files = get_image_files(test_path).sorted()
test_dl = learn.dls.test_dl(test_files)



## === cell 7
raw_logits, _ = learn.get_preds(dl=test_dl)
probs = torch.sigmoid(raw_logits)



## === cell 8
threshold = 0.5
class_names = learn.dls.vocab
pred_labels = []
for prob_vec in probs:
    idxs = (prob_vec >= threshold).nonzero(as_tuple=False).flatten().tolist()
    if idxs:
        labels = " ".join([class_names[i] for i in idxs])
    else:
        labels = "healthy"
    pred_labels.append(labels)



## === cell 9
submission = pd.DataFrame(
    {"image": [p.name for p in test_files], "labels": pred_labels}
)
submission.to_csv("submission.csv", index=False)
