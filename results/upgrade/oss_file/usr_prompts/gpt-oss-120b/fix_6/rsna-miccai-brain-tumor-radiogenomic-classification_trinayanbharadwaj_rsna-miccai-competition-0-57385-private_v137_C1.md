## Task
Predict the genetic subtype of glioblastoma using MRI (magnetic resonance imaging) scans to detect for the presence of MGMT promoter methylation.

## Metric
Area under the ROC curve between the predicted probability and the observed target.

For each `BraTS21ID` in the test set, you must predict a probability for the target `MGMT_value`. The file should contain a header and have the following format:

import os
import pandas as pd
import numpy as np




## === cell 1
TEST_PATH = "../input/rsna-miccai-brain-tumor-radiogenomic-classification/test"


def get_test_ids(path_test: str):
    """
    Scan the test directory and return a sorted list of BraTS21ID strings.
    Non‑numeric entries (e.g., stray 'test' folders) are ignored.
    IDs are returned without leading zeros; they will be zero‑padded later.
    """
    ids = []
    for entry in os.scandir(path_test):
        if entry.is_dir():
            name = entry.name
            if name.lstrip("0").isdigit():
                case_id = name.lstrip("0")
                ids.append(case_id if case_id != "" else "0")
    ids = sorted(ids, key=lambda x: int(x))
    return ids


try:
    test_ids = get_test_ids(TEST_PATH)
except Exception as e:
    print(f"Error reading test directory: {e}")
    test_ids = []
