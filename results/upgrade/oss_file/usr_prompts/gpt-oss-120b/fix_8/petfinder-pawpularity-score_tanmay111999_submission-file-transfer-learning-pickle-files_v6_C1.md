# 1. Kaggle task description

## Task
Predict engagement with a pet's profile based on the photograph for that profile.

## Metric
Root mean squared error.

## Submission Format
For each `Id` in the test set, you must predict a probability for the target variable, `Pawpularity`. The file should contain a header and have the following format:

```
Id, Pawpularity
0008dbfb52aa1dc6ee51ee02adf13537, 99.24
0014a7b528f1682f0cf3b73a991c17a0, 61.71
0019c1388dfcd30ac8b112fb4250c251, 6.23
00307b779c82716b240a24f028b0031b, 9.43
00320c6dd5b4223c62a9670110d47911, 70.89
etc.
```

## Dataset
- **train/** - Folder containing training set photos of the form **{id}.jpg**, where **{id}** is a unique Pet Profile ID.
- **train.csv** - Metadata (described below) for each photo in the training set as well as the target, the photo's Pawpularity score. The Id column gives the photo's unique Pet Profile ID corresponding the photo's file name.

The train.csv and test.csv files contain metadata for photos in the training set and test set, respectively. Each pet photo is labeled with the value of 1 (Yes) or 0 (No) for each of the following features:

- **Focus** - Pet stands out against uncluttered background, not too close / far.
- **Eyes** - Both eyes are facing front or near-front, with at least 1 eye / pupil decently clear.
- **Face** - Decently clear face, facing front or near-front.
- **Near** - Single pet taking up significant portion of photo (roughly over 50% of photo width or height).
- **Action** - Pet in the middle of an action (e.g., jumping).
- **Accessory** - Accompanying physical or digital accessory / prop (i.e. toy, digital sticker), excluding collar and leash.
- **Group** - More than 1 pet in the photo.
- **Collage** - Digitally-retouched photo (i.e. with digital photo frame, combination of multiple photos).
- **Human** - Human in the photo.
- **Occlusion** - Specific undesirable objects blocking part of the pet (i.e. human, cage or fence). Note that not all blocking objects are considered occlusion.
- **Info** - Custom-added text or labels (i.e. pet name, description).
- **Blur** - Noticeably out of focus or noisy, especially for the pet's eyes and face. For Blur entries, "Eyes" column is always set to 0.

## === cell 0
import os
import numpy as np
import pandas as pd
from tqdm import tqdm
from PIL import Image
import tensorflow as tf
from tensorflow.keras.applications.vgg16 import VGG16, preprocess_input

np.random.seed(42)
tf.random.set_seed(42)

BASE_PATH = "/kaggle/input/petfinder-pawpularity-score"



## === cell 1
train_df = pd.read_csv(os.path.join(BASE_PATH, "train.csv"))
test_df = pd.read_csv(os.path.join(BASE_PATH, "test.csv"))

print("Train rows:", len(train_df), "Test rows:", len(test_df))



## === cell 2
vgg_model = VGG16(
    weights="imagenet", include_top=False, pooling="avg", input_shape=(128, 128, 3)
)
vgg_model.trainable = False




## === cell 3
def load_image_features_tf(id_series, folder, batch_size=256):
    """
    Load and preprocess images using a tf.data pipeline, then extract VGG16 features.
    This eliminates the Python per‑image loop, keeping the exact same preprocessing
    and model, thus preserving feature values while greatly reducing runtime.
    """
    ids = id_series.tolist()
    paths = [os.path.join(BASE_PATH, folder, f"{img_id}.jpg") for img_id in ids]

    path_ds = tf.data.Dataset.from_tensor_slices(paths)

    def _load_and_preprocess(path):
        img = tf.io.read_file(path)
        img = tf.image.decode_jpeg(img, channels=3)
        img = tf.image.resize(img, [128, 128], method="bilinear")
        img = tf.cast(img, tf.float32)
        img = preprocess_input(img)
        return img

    img_ds = path_ds.map(_load_and_preprocess, num_parallel_calls=tf.data.AUTOTUNE)
    img_ds = img_ds.batch(batch_size).prefetch(tf.data.AUTOTUNE)

    features = vgg_model.predict(img_ds, verbose=0)
    return features




## === cell 4
train_image_features = load_image_features_tf(train_df["Id"], "train")
test_image_features = load_image_features_tf(test_df["Id"], "test")
print("Train image features shape:", train_image_features.shape)
print("Test image features shape:", test_image_features.shape)



## === cell 5
meta_columns = [
    "Subject Focus",
    "Eyes",
    "Face",
    "Near",
    "Action",
    "Accessory",
    "Group",
    "Collage",
    "Human",
    "Occlusion",
    "Info",
    "Blur",
]

X_train_meta = train_df[meta_columns].astype(np.float32).values
X_test_meta = test_df[meta_columns].astype(np.float32).values

X_train = np.hstack([X_train_meta, train_image_features])
X_test = np.hstack([X_test_meta, test_image_features])

y_train = train_df["Pawpularity"].values

from sklearn.ensemble import GradientBoostingRegressor

gbr = GradientBoostingRegressor(
    n_estimators=300, learning_rate=0.05, max_depth=3, random_state=42
)
gbr.fit(X_train, y_train)



## === cell 6
test_pred = gbr.predict(X_test)

submission = pd.DataFrame({"Id": test_df["Id"], "Pawpularity": test_pred})
submission = submission[["Id", "Pawpularity"]]

submission_path = "submission.csv"
submission.to_csv(submission_path, index=False)
print(f"Submission written to {submission_path}, shape: {submission.shape}")
